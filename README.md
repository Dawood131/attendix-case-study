# Attendix | Attendance & Payroll System

Case study of an enterprise attendance management system, built by a cross-functional team and live in the client's production environment.

## About the System

Attendix handles employee check-in/out, leave requests, payroll, and location-based attendance tracking.

## My Role

I worked as a frontend developer on this project:

- Built frontend modules using React, Redux Toolkit, and Tailwind CSS
- Integrated REST APIs with the frontend and managed application state
- Contributed basic-level API work on the backend alongside the backend team

The core backend logic, including location-based tracking, was handled by the backend team.

## Tech Stack

`React` `Redux Toolkit` `REST API` `Tailwind CSS`
